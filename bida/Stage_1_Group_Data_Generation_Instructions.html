Stage 1 • Pre-Class Group Task

Generate Your Group Sales Activity Dataset

Create, freeze, check, and submit a unique three-month synthetic dataset before the analytics class.

Purpose of this task

Your group will generate its own synthetic operational dataset representing the daily activity of six sales managers over a 90-day period. The dataset will later be used for PivotTable, attendance, sales, expenditure, trend, and relationship analysis in class.

Important: Each group will obtain different values because the dataset uses random generation. Different numbers are expected.

Dataset structure

Create the following seven columns in Excel, beginning in Row 1:

ColumnVariableMeaning
ADateScheduled activity date
BRecord_IDUnique record number
CRegionNorth, Central, South, or East
DManagerManager 1 to Manager 6
EStatusPresent or Absent
FDaily_Promotion_SpendDaily promotional expenditure when present
GTotal_SalesDaily sales generated when present

90 days × 6 managers = 540 possible manager-day records before attendance is considered.

Step-by-step data generation

1

Generate the date

In A2, enter:

=DATE(2026,6,1)+INT((ROW()-2)/6)

Each date will repeat six times—once for each manager. Drag the formula down until Row 541.

2

Create a unique Record ID

In B2, enter:

="S"&TEXT(ROW()-1,"000")

This generates IDs such as S001, S002, S003 and so forth.

3

Assign a region randomly

In C2, enter:

=CHOOSE(RANDBETWEEN(1,4),"North","Central","South","East")

A manager may appear in different regions on different dates.

4

Generate the six managers

In D2, enter:

=CHOOSE(MOD(ROW()-2,6)+1,"Manager 1","Manager 2","Manager 3","Manager 4","Manager 5","Manager 6")

The formula cycles through all six managers for every scheduled date.

5

Generate attendance status

In E2, enter:

=IF(RAND()<=0.85,"Present","Absent")

This gives each manager approximately an 85% probability of being present on a scheduled day.

6

Generate daily promotional expenditure

In F2, enter:

=IF(E2="Present",RANDBETWEEN(500,2000),"")

If the manager is absent, promotional expenditure is left blank because no activity took place.

7

Generate total sales

In G2, enter:

=IF(E2="Present",ROUND(MAX(2000,MIN(15000,F2*5+RANDBETWEEN(-1500,1500))),0),"")

This creates a positive but imperfect relationship between promotional expenditure and sales. Absent records remain blank.

8

Fill all formulas down

Copy or drag the formulas in A2:G2 down to Row 541.

Freeze your generated dataset

Do not skip this step. RAND() and RANDBETWEEN() recalculate whenever Excel recalculates. Your values will keep changing until you convert the formulas to fixed values.
  1. Select the completed dataset.
  2. Copy it.
  3. Use Paste Special → Values.
  4. Save the workbook.

Check your dataset before submission

  • The dataset should contain 540 scheduled manager-day records.
  • Each date should initially appear six times.
  • Managers should cycle from Manager 1 to Manager 6.
  • Region should vary across records.
  • Status should contain both Present and Absent.
  • Absent rows should have blank Promotion Spend and Total Sales.
  • Present rows should contain numeric Promotion Spend and Total Sales.
  • Values must be frozen before submission.
