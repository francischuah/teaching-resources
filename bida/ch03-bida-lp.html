2. Preattentive attributes: guide attention

Our eyes notice some visual differences very quickly. Used carefully, these attributes help the reader locate what matters.

Colour

Highlight an important category, exception or result.

Size

Make an important item more prominent than surrounding information.

Shape

Differentiate groups or draw attention to a special observation.

Length

Bars use length to make magnitude easier to compare.

Use emphasis with purpose. If everything is highlighted, nothing is highlighted.

4. Start with the question — not the chart

An analyst does not begin with “I want to create a pie chart.” Begin with what you need to learn from the data.

COMPARE

Which is bigger or smaller?

Usually: Bar / column chart

TREND

What is changing over time?

Usually: Line chart

DISTRIBUTION

How are values spread?

Usually: Histogram

RELATIONSHIP

Do two variables move together?

Usually: Scatter plot

6. How to read the four core visuals

1
Bar / Column — Comparison
Look for the highest, lowest, ranking and size of differences. Sort categories when ranking matters.
2
Line — Trend
Look for direction, peaks, dips, turning points and periods of unusual change. Time should normally progress logically along the X-axis.
3
Histogram — Distribution
Look for concentration, spread, shape and unusually high/low observations. Histograms group numerical values into ranges.
4
Scatter — Relationship
Look for positive, negative or no obvious association. A visual relationship does not prove that one variable causes the other.

7. Good visual design: make the message easy to see

Do

Use a meaningful title • label axes clearly • use readable scales • sort when useful • highlight selectively • keep colours consistent • remove unnecessary clutter.

Avoid

Unnecessary 3D • too many colours • excessive gridlines • decorative effects • too many pie slices • misleading axis scales • labels that compete with the data.

8. A technically correct chart can still mislead

Suppose sales increase from RM95m to RM100m — a 5.3% increase. A truncated axis can make the change look dramatic; a zero baseline shows the magnitude in context.

Always ask: “Does the visual impression fairly represent the underlying numbers?”

9. Explore quickly with PivotTables

PivotTables let you ask different questions of the same dataset without rewriting formulas each time.

The logic

ROWSGenre
COLUMNSRating
VALUESCount of Movies / Average Box Office
FILTERSYear Released

Change the question

How many movies are in each genre?
Which genre has the highest average receipts?
How do Genre × Rating combinations differ?
What changes if we filter to newer movies?

10. PivotTable → PivotChart

A PivotTable summarises the values. A PivotChart makes the pattern easier to see. Filtering or rearranging the PivotTable changes the view of the analysis.

Same dataset → different question → different summary → different visual insight.

12. Don't stop at the chart: interpret it

A chart is evidence. Your job is to explain what that evidence means.

1 · Finding

What pattern do you see?

2 · Evidence

Which values support the finding?

3 · Meaning

Why might this matter?

4 · Caution

What should you avoid claiming?

Example structure: “Genre A shows the highest average box-office receipts in this dataset. Its average is higher than the other categories shown. This suggests Genre A is strongly represented among these top-performing movies; however, the chart alone does not prove that genre causes higher receipts.”

13. Which visual should I use?

Need exact values?
→ Table
Compare categories?
→ Bar / Column
Show change over time?
→ Line
Understand numerical spread?
→ Histogram
Examine two quantitative variables?
→ Scatter
Explore several views quickly?
→ PivotTable / PivotChart
Monitor several KPIs together?
→ Dashboard
Not sure?
→ Return to the business question.

14. Common mistakes to remember

!
Choosing a chart because it looks impressive rather than because it answers the question.
!
Using too many colours, borders, labels or effects until the data become harder to see.
!
Reporting what the chart contains without explaining the pattern or business meaning.
!
Interpreting association as causation.
!
Using misleading scales or visual emphasis that exaggerates the underlying difference.
