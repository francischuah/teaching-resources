COUNTIF

How many Toyota models are in the Top 20?

=COUNTIF(C4:C23,"Toyota")

C4:C23 is the Manufacturer column. Excel counts every cell that matches Toyota.

Result: 5
COUNTIFS

How many Toyota models sold more than 250,000?

=COUNTIFS(C4:C23,"Toyota", E4:E23,">250000")

Excel counts a row only when both conditions are true: Manufacturer = Toyota and 2021 Sales > 250,000.

Result: 4
COUNTIF = one condition   •   COUNTIFS = multiple conditions. Gold cells show the first condition being tested.

OLDER LOOKUP FUNCTIONS

What about VLOOKUP and HLOOKUP?

VLOOKUPVertical lookup
1 Find “Honda CR-V” → 2 move across → 3 return 2021 Sales
Excel worksheet
BCDE
3ModelManufacturer20202021
4Honda CR-VHonda333,584361,271
5Toyota CamryToyota294,367313,795
=VLOOKUP("Honda CR-V",B4:E23,4,FALSE)

VLOOKUP searches down the first column, finds the model, then moves across the same row to return the requested value.

HLOOKUPHorizontal lookup
1 Find “Honda CR-V” → 2 move down → 3 return 2021 Sales
Excel worksheet
BCD
3ModelHonda CR-VToyota Camry
42020 Sales333,584294,367
52021 Sales361,271313,795
=HLOOKUP("Honda CR-V",B3:D5,3,FALSE)

HLOOKUP searches across the first row, finds the model, then moves down the same column to return the requested value.

Same lookup idea, different direction: VLOOKUP works vertically; HLOOKUP works horizontally. You may see both in older workbooks. For new analysis, we concentrate on XLOOKUP.
