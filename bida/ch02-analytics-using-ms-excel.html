Purpose & Learning Focus

Excel formulas are essential tools for quick calculations and data analysis. Functions such as SUM, MIN, MAX and AVERAGE simplify operations on large datasets. In this chapter, you will also use logical, counting and lookup functions to ask useful questions of data.

Dataset used throughout top20vehicles2021 — the same vehicle-sales dataset used in the chapter slides.

What is an Excel Formula?

A formula is an instruction that tells Excel to calculate or evaluate something. A formula begins with = and may contain cell references, operators and functions.

Basic formula

=D2-E2

Uses operators directly. Cell references make the calculation update when the data changes.

Excel function

=SUM(D2:D21)

A function is a built-in formula. Here, D2:D21 means all cells from D2 through D21.

Logical Functions

Logical functions evaluate conditions and return a result based on whether the condition is TRUE or FALSE.

IF — choose between two outcomes

=IF(D2>E2,"PROFIT","LOSS")

Using the chapter dataset, compare 2021 sales (D) with 2020 sales (E). If D2 is larger than E2, the result is PROFIT; otherwise it is LOSS. For Ford F-Series, 726,004 is below 787,423, so the result is LOSS.

Try 4 — IF

Now try this in Excel: Enter the IF formula in a new column and fill it down for all 20 vehicles.

AND — all conditions must be TRUE

=AND(D2>250000,E2<400000)

The slide example asks which cases meet the stated conditions. AND returns TRUE only when every condition inside AND is TRUE.

Read the formula carefully. The slide wording describes sales “between 250,000 and 400,000 for both years,” while the displayed formula checks only D>250000 and E<400000. If the intention is to test the full range for both years, four conditions are needed: =AND(D2>250000,D2<400000,E2>250000,E2<400000).

Try 5 — AND

Now try this in Excel: Compare the two-condition chapter formula with the four-condition “between” formula.

OR — at least one condition must be TRUE

=OR(D2>250000,E2>250000)

This queries whether sales are above 250,000 in either 2021 or 2020. OR returns TRUE when one or both conditions are TRUE.

LOOKUP Functions for Database Queries in Excel

Lookup functions let you search a table and retrieve related information. They are useful when a worksheet behaves like a small database.

VLOOKUP — search vertically

VLOOKUP searches for a value in the first column of a table and returns a value from another column in the same row.

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

The chapter uses a value-to-indicator table to classify vehicle sales:

Common Mistakes

  • Forgetting the opening = sign.
  • Using the wrong range, such as D2:D20 instead of D2:D21.
  • Confusing AND with OR: AND requires all conditions; OR requires at least one.
  • Reversing the TRUE/FALSE outputs in an IF statement.
  • Forgetting quotation marks around text returned by IF, such as "PROFIT".
  • Using COUNT when you really need COUNTIF with a criterion.
  • For VLOOKUP, forgetting that the lookup value must be in the first column of the table array.
  • For HLOOKUP, forgetting that the lookup value must be in the first row.
  • When using approximate VLOOKUP/HLOOKUP, not arranging threshold values in ascending order.
  • Copying a lookup formula without fixing the lookup table reference with $, e.g. $I$2:$J$4.

Key Takeaway

Excel analytics begins with asking the right question, then choosing the function that matches it. Use SUM/MIN/MAX/AVERAGE to summarize numbers; IF/AND/OR to evaluate conditions; COUNT/COUNTIF to quantify cases; and VLOOKUP/HLOOKUP to retrieve or classify information from lookup tables.
